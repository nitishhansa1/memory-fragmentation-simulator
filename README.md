# Memory Fragmentation Analysis Tool

An interactive simulation tool that demonstrates and analyzes internal and external memory fragmentation caused by dynamic memory allocation strategies.

## Features
- **Simulate Dynamic Memory Allocation:** Visualize how memory is allocated and deallocated over time.
- **Visualize Fragmentation:** See internal and external memory fragmentation graphically.
- **Compare Algorithms:** Compare First Fit, Best Fit, and Worst Fit memory allocation algorithms.
- **Analytics:** View detailed statistics and charts comparing utilization and fragmentation.

## Technologies Used
- HTML5, CSS3, JavaScript (ES6+)
- [Vite](https://vitejs.dev/) - Frontend Tooling
- [Chart.js](https://www.chartjs.org/) - Analytics and data visualization

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
